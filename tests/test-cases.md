# Calculation Test Cases

These cases are intended as regression checks for the browser calculation engine.

## Core numbers

- 15 August 1990 → Birth Number 6; year digit sum 19; Destiny Number 6.
- 15 August 1991 → Birth Number 6; year digit sum 20; Destiny Number 7.
- 1 January 2000 → Birth Number 1; year digit sum 2; Destiny Number 4.
- 29 February 2000 → Birth Number 2; year digit sum 2; Destiny Number 5.

## Name systems

Use known letter mappings from the documented Chaldean and Pythagorean tables and verify letter-by-letter totals before reduction.

## Edge cases

- Empty name
- Missing DOB
- Future DOB
- Invalid date
- Unicode characters in name
- Apostrophes and hyphens
- Multiple spaces
- Single-word name
- Very long name

## Safety / presentation

- Display the methodology used for each result.
- Clearly label numerology as a belief/traditional framework rather than scientific prediction.
- Do not imply medical, financial, legal, or other high-stakes certainty from numerology.
